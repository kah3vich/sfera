## Commands

| Command            | Description              |
| ------------------ | ------------------------ |
| `npm run dev`      | start dev server         |
| `npm run build`    | build for production     |
| `npm run fonts`    | convert fonts to woff    |
| `npm run svg`      | create svg sprite        |
| `npm run otf2ttf`  | convert otf to ttf       |
